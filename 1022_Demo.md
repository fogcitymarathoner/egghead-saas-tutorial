## [MongoDB](https://cloud.mongodb.com/v2/6712d780d2458d4ac9941935#/metrics/replicaSet/6712ed87778aff29071dc4e0/explorer/Project0/User/find)
2 application collections

1) User - Created at signin
1) Subscriptions - The Product

### Coded Business Rules
* Oauth Signup/Authentication (**github**), creates ***user*** record
* **Stripe Subscription** 2 states ***free*** and ***premium*** signs up new user and charges for subscription

#### Visual Effects
* Login/Logout button toggles if logged in or logged out
* **Premium** button is hidden if user has not subscribed

# Demo Instructions
## Preparation
1) have MongoDB and stripe dashboards open
1) make sure github is logged-in
1) log out of nextJS app
1) delete MongoDB users and subscriptions table
2) run ./stripe login # note: stripe.exe is in current directory
3) run ./stripe listen --forward-to localhost:3000
